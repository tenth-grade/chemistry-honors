Current exam scope

What to know

Homogeneous vs. heterogeneous mixtures

  • Homogeneous: uniform composition throughout.
  • Heterogeneous: nonuniform composition.
  • Distinguish element, compound, pure substance, solution, and mixture.
  • Be able to justify a classification, not only name it.

Dimensional analysis

  • Start with the given quantity.
  • Multiply by conversion factors equal to 1.
  • Arrange factors so unwanted units cancel.
  • Use multi-step conversions when needed.

Physical vs. chemical changes

  • Physical change preserves chemical identity.
  • Chemical change forms one or more new substances.
  • Possible evidence: precipitate, gas formation, heat/light, sustained color change.
  • Evidence must be interpreted in context.

Density

  • D = m/V
  • m = D × V
  • V = m/D
  • Common units: g/mL and g/cm³.
  • Water displacement can determine irregular-object volume.

Electromagnetic radiation

  • Know the spectrum order from radio to gamma.
  • Use c = λν.
  • Longer wavelength means lower frequency.
  • Higher frequency means higher photon energy.

Basic conversions

  • Know kilo, centi, milli, micro, and nano relationships.
  • Use exact conversion relationships expected in class.
  • Convert units before substituting into formulas when units do not match.

Isotopes

  • Atomic number = protons.
  • Mass number = protons + neutrons.
  • Neutrons = mass number − atomic number.
  • Isotopes have the same protons but different neutrons.
  • Average atomic mass is abundance-weighted.

Significant figures & scientific notation

  • Identify significant digits correctly, including leading, captive, and trailing zeros.
  • Round measurements to a requested number of significant figures.
  • Use scientific notation when needed to make significant figures unambiguous.
  • Apply sig-fig rules after multiplication/division and decimal-place rules after addition/subtraction.

Honors-level synthesis

  • Expect some questions to combine two skills.
  • Examples: displacement + density, conversions + density, wavelength + frequency, isotope notation + neutron count.
  • Explain why an answer is reasonable when asked.

Worked Honors examples

Model the setup

Density by displacement: A metal sample has mass 47.5 g. Water rises from 22.5 mL to 28.6 mL. Volume = 28.6 − 22.5 = 6.1 mL. Density = 47.5 g ÷ 6.1 mL ≈ 7.8 g/mL.

Dimensional analysis: 72.0 km/h × (1000 m / 1 km) × (1 h / 3600 s) = 20.0 m/s.

Electromagnetic radiation: For ν = 6.00 × 10¹⁴ Hz, λ = c/ν = (3.00 × 10⁸ m/s)/(6.00 × 10¹⁴ s⁻¹) = 5.00 × 10⁻⁷ m.

Average atomic mass: 10.0 amu at 20.0% and 11.0 amu at 80.0% gives (10.0 × 0.200) + (11.0 × 0.800) = 10.8 amu.

After each test

Classify the mistake before reviewing the answer

Concept error
The underlying rule was misunderstood.
Setup error
The right concept was known but the equation or factor chain was wrong.
Unit error
Units were missing, inconsistent, or failed to cancel.
Arithmetic error
The setup was correct but calculation execution failed.

Redo every missed question without looking at the answer. If the second attempt is still wrong, return to the topic explanation before doing more questions of the same type.
