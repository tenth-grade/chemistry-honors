# Chemistry Honors Study Hub

Interactive Grade 10 Chemistry Honors exam-preparation site.

## Current exam topics

- Homogeneous and heterogeneous mixtures
- Dimensional analysis
- Physical and chemical changes
- Density and density word problems
- Electromagnetic radiation
- Basic metric conversions
- Isotopes and average atomic mass

## Site capabilities

- Focused concept review
- Formula sheet
- Worked Honors-level examples
- Three interactive practice tests
- Immediate scoring and explanations
- Error-classification workflow for remediation
- Mobile-friendly and printable layout

## Reference material

The study hub uses the supplied exam-topic notes as its primary scope. CK-12 Chemistry FlexBook 2.0 is included as a secondary external reference for broader explanations and examples:

https://flexbooks.ck12.org/cbook/ck-12-chemistry-flexbook-2.0/

## GitHub Pages

The site entry point is `index.html`.

To publish:

1. Open **Settings → Pages** for this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`.
4. Save.

Expected URL:

https://tenth-grade.github.io/chemistry-honors/
